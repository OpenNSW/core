# Documentation

OpenNSW Core is documented as an **open software library** (this repository
alone: importable Go modules). Indicator 5–style install, test, contribute, and
use paths are covered below—no country deployment or separate demo app is part
of that scope.

| Document | Purpose |
| --- | --- |
| [using.md](using.md) | Install modules into an app, external systems, supported usage, behaviour |
| [releases.md](releases.md) | Module tags, how downstream apps upgrade, fork vs upstream |
| [contributing/development.md](contributing/development.md) | Clone, `make setup`, test, fork, pull request |
| [contributing/reporting-issues.md](contributing/reporting-issues.md) | Bug and feature reports |
| [../CONTRIBUTING.md](../CONTRIBUTING.md) | Hooks, lint, commit convention, CI overview |
| [../README.md](../README.md) | Package index, architecture diagram, technology stack |
| [../SECURITY.md](../SECURITY.md) | Vulnerability reporting |
